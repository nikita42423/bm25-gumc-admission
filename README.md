# Помощник абитуриента ГУИМЦ

Поиск ответов в документах приёмной комиссии для абитуриентов
с нарушениями слуха и их родителей.

## Пользователь
Абитуриент ГУИМЦ / его родитель.

## Основной сценарий
1. Пользователь вводит вопрос в текстовом чате.
2. Система ищет релевантные фрагменты в документах приёмной комиссии.
3. LLM формирует короткий ответ.
4. Пользователь видит ответ и ссылку на источник.
