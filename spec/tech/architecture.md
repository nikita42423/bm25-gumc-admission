# Архитектура

## Компоненты
```
Браузер (app/static: HTML/CSS/JS)
   │  POST /api/ask {question}
   ▼
FastAPI (app/main.py)
   ├─ поиск BM25 по фрагментам документов приёмной комиссии   (в работе)
   └─ LLM: короткий ответ по найденным фрагментам               (в работе)
```

Сервер отдаёт и API, и статические файлы фронтенда — один процесс, запуск `python -m app`.

## API
### `POST /api/ask`
Запрос:
```json
{ "question": "Какие документы нужны для поступления?" }
```
Ответ:
```json
{
  "answer": "Короткий ответ…",
  "sources": [
    { "title": "Правила приёма ГУИМЦ, раздел 4", "fragment": "Текст фрагмента…", "url": "…" }
  ]
}
```
`question` — от 1 до 500 символов. Пустой `answer` и пустой `sources` — ответ не найден.

## Стек
Python 3.11, FastAPI, uvicorn. Фронтенд без сборки и фреймворков.
