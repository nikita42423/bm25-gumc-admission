# Сценарии

Ответственный: Колупаев Н. Н. (зона «Продукт и интерфейс»)

## С1. Основной: вопрос → ответ с источником
**Пользователь:** абитуриент или родитель.

1. Пользователь открывает сайт и видит приветствие и примеры вопросов.
2. Вводит вопрос своими словами, например «Какие документы нужны для поступления?»,
   и нажимает «Найти» (или Enter).
3. Вопрос появляется в чате справа, под ним — «Ищу ответ в документах…».
4. Система находит до 5 подходящих фрагментов документов (BM25) и передаёт их LLM.
5. Появляется ответ (2–5 предложений) и блок «Источники»: название документа,
   фрагмент текста, ссылка на документ. Слова из вопроса подсвечены.

**Проверка:** ответ пришёл, есть хотя бы один источник, ответ не противоречит источнику.

## С2. Вопрос из примеров
1. На стартовом экране пользователь нажимает кнопку-пример.
2. Дальше — как в С1, шаги 3–5.

**Проверка:** нажатие кнопки отправляет вопрос без ручного ввода.

## С3. Ответ не найден
1. Пользователь задаёт вопрос, которого нет в документах (например, «Какая погода в Москве?»).
2. Поиск не находит подходящих фрагментов (или LLM видит, что в них нет ответа).
3. Система отвечает: «Не нашёл ответа в документах. Попробуйте переформулировать вопрос».

**Проверка:** система не выдумывает ответ без источника.

## С4. Ошибка сети или сервера
1. Пользователь отправляет вопрос, сервер недоступен.
2. Появляется сообщение: «Не удалось получить ответ. Проверьте соединение и попробуйте ещё раз».
3. Кнопка «Найти» снова активна, можно повторить.

## С5. Проверка ответа по источнику
1. После ответа пользователь открывает источник по ссылке.
2. Открывается документ приёмной комиссии, в котором можно найти показанный фрагмент.

**Проверка:** ссылка ведёт на нужный документ на bmstu.ru.

## Ограничения для всех сценариев
- Вопрос: от 1 до 500 символов.
- Время ответа — до 10 секунд; пока идёт поиск, пользователь видит индикатор.
- Всё общение только текстом.
