## 2026-11-19
- Корпус: `scripts/build_corpus.py` — 12 PDF → 491 фрагмент по пунктам (`data/corpus/fragments.jsonl`).
- Поиск: своя реализация индекса и BM25 (k1 = 1.5, b = 0.75), лемматизация pymorphy3, стоп-слова,
  название документа в индексе, синонимы для слов абитуриента.

- Benchmark: `queries.json` (27 вопросов, id фрагментов), `benchmark/run.py` — Recall@5, MRR@5,
  Accuracy, Correct Rejection Rate, сравнение настроек. Recall@5 = 0.353 (потолок 0.928), MRR@5 = 0.596.
- Тесты: `tests/` — BM25 на примере из занятия 3, предобработка, корпус, API с заглушкой LLM, цепочка LLM.
- Выбор модели рядом с кнопкой «Найти»: Авто (Ollama → YandexGPT), Ollama, Яндекс, Нет (только
  фрагменты); под ответом подпись, какая модель его написала. API: поле `llm` в запросе и ответе.
- Ollama вызывается без системного прокси (прокси отвечал 503 вместо локального сервера).
- Документация: `spec/tech/rag.md`, `architecture.md`, README (настройка LLM, проверка);
  задача Ж4 (эталоны ответов и вопросы-ловушки).
