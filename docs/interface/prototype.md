# Прототип интерфейса

Реализация: `app/static/index.html`, `app/static/css/style.css`, `app/static/js/app.js`.

## Экран (один)
1. **Шапка** — неоновый логотип ГУИМЦ (44 px), название «Помощник абитуриента ГУИМЦ», подзаголовок.
2. **Лента чата** — приветствие и кнопки-примеры вопросов; затем сообщения пользователя (справа)
   и ответы системы (слева).
3. **Ответ** — короткий текст + блок «Источники»: название документа, фрагмент текста, ссылка.
   Слова из вопроса подсвечены неоновым градиентом.
4. **Поле ввода** внизу + кнопка «Найти».

Состояния: «Ищу ответ в документах…», «Не нашёл ответа…», ошибка сети.

Шапка и чат выровнены по одной центральной колонке шириной 820 px.

## Анимации и скроллбар
- Сообщения плавно появляются: вопрос выезжает справа, ответ — слева; источники — с небольшой задержкой.
  Пока идёт поиск, текст «Ищу ответ…» мягко пульсирует. При системной настройке
  «уменьшить движение» анимации отключаются.
- Скроллбар чата: ползунок и стрелки циановые, дорожка прозрачная (сливается с фоном).
  В Firefox стрелок нет — там только цвет ползунка.

## Палитра
| Токен | Цвет | Назначение |
|---|---|---|
| `--bg` | `#0b1020` | фон страницы (тёмно-синий) |
| `--surface` | `#151a2b` | карточки, шапка (графит) |
| `--text` | `#e6e9f2` | основной текст |
| `--text-muted` | `#9aa3bd` | второстепенный текст |
| `--cyan` → `--pink` | `#00ffff` → `#ff77ff` | неоновый градиент |

## Правила неона
Градиент используется **дозированно** — только для активных элементов:
кнопка «Найти», подсветка ключевых слов, иконки, логотип, рамка фокуса.
Обычный текст и фон — спокойные, чтобы текст легко читался.

## Доступность
Аудитория — люди с нарушениями слуха, поэтому вся информация только в виде текста:
без звука и видео. Крупный шрифт (18 px), высокий контраст, работает с клавиатуры, адаптив до 360 px.

## Логотип
Исходник — `logo_guimc.png` (растр 6100×7719, в `logo_guimc.svg` он просто вложен как картинка, 786 КБ).
Скрипт `scripts/vectorize_logo.py` обводит его в настоящий вектор: ухо и надпись — голубой `#00ffff`,
звезда — золотой `#ffd54a`. Результат — `app/static/img/logo.svg` (~6 КБ). Свечение — CSS `drop-shadow`.
