# Задачи: Тошниёзов Жавохирбек — «Корпус и benchmark»

## О проекте за 1 минуту
«Помощник абитуриента ГУИМЦ» — сайт-чат для абитуриентов с нарушениями слуха и их родителей.
Пользователь пишет вопрос → сервер ищет подходящие фрагменты в документах приёмной комиссии
(поиск BM25) → LLM пишет короткий ответ → пользователь видит ответ и источник.

Твоя зона — **данные**: документы, по которым идёт поиск (корпус), и тестовые вопросы,
по которым мы проверяем качество поиска (benchmark). Программировать не нужно.

## Что можно менять
Только эти файлы и папки:
- `data/` — скачанные документы и список источников
- `benchmark/` — тестовые вопросы
- `spec/tech/rag.md` — только раздел «1. Корпус»

Всё остальное **не трогать**. Правила работы с git — в [docs/team.md](../team.md).

## Термины (выучить — спросят на защите)
- **Корпус** — все документы, в которых ищем ответ.
- **Фрагмент** — кусок документа (обычно пункт правил), который находит поиск и показывает пользователю.
- **BM25** — формула, которая оценивает, насколько фрагмент подходит к вопросу: учитывает, сколько раз
  в нём встречаются слова вопроса и насколько эти слова редкие.
- **Benchmark** — набор тестовых вопросов, для которых заранее известно, какие фрагменты правильные.
- **Recall@5** — какая доля правильных фрагментов попала в первые 5 результатов поиска (от 0 до 1, больше — лучше).
- **MRR** — насколько высоко стоит первый правильный фрагмент: на 1-м месте = 1, на 2-м = 0.5, на 3-м = 0.33…

| Приложение 2. Порядок приема… на базе СПО | `app02_spo.pdf` |
| Приложение 3. Особенности приема… на второе высшее | `app03_second_degree.pdf` |
| Приложение 5. Порядок предоставления особых прав… олимпиад | `app05_olympiads.pdf` |
| Приложение 6. Перечень индивидуальных достижений… бакалавриата | `app06_achievements.pdf` |
| Приложение 8.1. Перечень НП(С) при приёме на 1-й курс | `app08_1_programs.pdf` |
| Приложение 8.3. Детализированная целевая квота | `app08_3_target_quota.pdf` |
| Приложение 10. Порядок проведения вступительных испытаний | `app10_exams.pdf` |

Создай файл `data/sources.csv` — по строке на документ (ссылку бери: правый клик по документу → «Копировать адрес ссылки»):
```
file,title,url
rules_2026.pdf,Правила приёма 2026,https://...
app11_exams_ovz.pdf,Приложение 11. Вступительные испытания для лиц с ОВЗ,https://...
```
Эти названия и ссылки пользователь увидит в блоке «Источники».

### Ж2. Проверить и дополнить вопросы benchmark
Файл `benchmark/queries.md` — там 22 вопроса.
1. Прочитай каждый вопрос. Если звучит неестественно — перепиши так, как спросил бы абитуриент или его родитель.
2. Добавь **3–5 своих вопросов** (номера 23–27). Правило: своими словами, не копировать фразы из документов.

### Ж3. Найти ответы в документах (главная задача)
Для **каждого** вопроса открой ожидаемый документ (колонка «Где ожидаем ответ»), найди пункты,
которые отвечают на вопрос, и запиши их номера в колонку «Релевантные фрагменты».
Пример: `Правила п. 4.2, п. 4.3, п. 4.5`.
- Нужно **не меньше трёх** пунктов на вопрос (требование методички).
- Если ответа в документах нет — вопрос замени другим.
- Если ответ нашёлся в другом документе — исправь колонку «Где ожидаем ответ».

Позже капитан превратит номера пунктов в id фрагментов и запустит подсчёт метрик.
